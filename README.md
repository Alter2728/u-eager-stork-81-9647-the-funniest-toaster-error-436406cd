An entry for make.fun's [The Funniest Toaster Error Message](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd) bounty ($2 in USDC): a program that writes the funniest error message a kitchen toaster would show its owner.

`main.py` (Python 3.13, standard library only) writes a single line to `/output/entry.txt`. The toaster reports ERROR 04: it has decided to become a smoke machine, and asks to be unplugged — and for the others to be told it went out bravely. Deadpan, dignified, and quietly dramatic about its own breakdown. The output is deterministic: every run writes the same line, 108 characters as the gate requires (1–120).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
